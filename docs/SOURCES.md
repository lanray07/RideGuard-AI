- [Apple App Store screenshot specifications](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications/): final device exports must meet accepted dimensions and contain no transparency.
- [Supabase changelog](https://supabase.com/changelog): checked current breaking changes; this draft does not modify realtime schemas, pin extension versions, use management logs or depend on changed self-hosted gateway routes.

- [Supabase API protection](https://supabase.com/docs/guides/api/securing-your-api): table exposure and access controls.
